## 🌍 Sobre o Projeto

O **EcoRewards** é uma plataforma digital focada em sustentabilidade, que transforma reciclagem em **recompensas reais**.

A proposta é simples:
> quanto mais você recicla, mais você ganha.

O sistema foi projetado para suportar **múltiplos usuários simultâneos**, com sincronização em tempo real e arquitetura pronta para escalar em ambiente cloud.

## ⚙️ Tecnologias

- ☁️ **Cloudflare** → hospedagem e distribuição  
- 🧠 **NoSQL Database** → flexibilidade e performance  
- 🔄 **Realtime Sync** → sincronização entre usuários  
- 💻 **Web (HTML, CSS, JS)** → interface responsiva  
- ⚡ **Arquitetura escalável** → preparada para crescimento
