# EcoRewards — Estrutura separada para GitHub

Projeto reorganizado com os arquivos separados por linguagem:

- `html/` → páginas HTML
- `css/` → estilos de cada página
- `js/` → scripts de cada página
- `data/mer.json` → JSON vazio para você preencher com o MER

## Observações
- Os links de CSS e JS já foram ajustados.
- Fontes do Google e ícones do Phosphor continuam sendo carregados por CDN.
- O arquivo `data/mer.json` está vazio por padrão.

## Sugestões de melhoria
1. Centralizar estilos compartilhados em um `global.css`.
2. Criar um `main.js` reutilizável para dark mode, navegação e componentes comuns.
3. Adicionar uma pasta `assets/` para imagens, logos e ilustrações.
4. Padronizar navegação entre todas as páginas.
